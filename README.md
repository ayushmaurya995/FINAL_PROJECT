# Financial KPI Analysis — Business Intelligence Project

An end-to-end financial performance analysis project built around the original Power BI report and Excel workbook, expanded with a browser-based interactive dashboard, analytical methodology, and reusable SQL examples.

## What the analysis covers
- Revenue and profit performance
- Profit margin and cost of goods sold
- Discount impact
- Monthly trends
- Segment, region, and product contribution
- Filtered CSV export from the interactive portfolio edition

## Run the interactive dashboard
Open dashboard/index.html in any modern browser. It is a self-contained HTML/CSS/JavaScript dashboard and requires no build tools or API keys.

> **Data transparency:** The browser dashboard currently uses an illustrative generated dataset to demonstrate filtering, charting, KPI calculations, and export behavior. It is not a transcription of the original Excel workbook or Power BI model. Use the original workbook and PBIX for the source analysis. Do not cite the illustrative dashboard figures as actual business results.

## KPI definitions
| KPI | Definition |
|---|---|
| Net Revenue | Gross sales less discounts |
| COGS | Direct cost of goods sold |
| Profit | Net revenue less COGS |
| Profit Margin | Profit divided by net revenue |
| Discount Impact | Discounts granted as a share of gross sales |
